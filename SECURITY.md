# Security policy

## Supported code

LiuYao is in early development. Security fixes target the current `main` branch unless a release-specific policy is published later.

## Reporting a vulnerability

Do not publish vulnerability details in a public issue.

Use GitHub's private vulnerability reporting flow when it is available for this repository. If it is unavailable, open a minimal issue asking the maintainer for a private contact channel and omit technical vulnerability details.

Include the affected revision, impact, reproduction steps, and any suggested mitigation in the private report.

## Scope

Security reports can include dependency vulnerabilities, PWA caching behavior, unsafe data handling, supply-chain issues, or future storage and network features.
