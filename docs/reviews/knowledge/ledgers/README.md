# Knowledge audit ledgers

This directory is the committed root for future scoped audit ledgers. It currently contains no review decisions. A directory marker is not source comparison, approval, certification, or completion evidence.

The expected-unit registry and version-1 ledger contract are documented in the [knowledge-model audit contract](../../../design-docs/knowledge-model.md#approved-versioned-audit-contract). Real decisions require review by their recorded owners; separate verification and final certification remain owned by feats 095 and 096. Follow the [AI review policy](../../../product-specs/knowledge-quality.md#group-units-and-independent-evidence); the version-1 `specialistReview` field also accepts recorded AI review.
