# Web font assets

The app uses one self-hosted family, Source Serif 4, for headings, body text, controls, and diagnostic values.

- Asset: `source-serif-4-roman.woff2` (429,100 bytes).
- Source: Adobe's [Source Serif release](https://github.com/adobe-fonts/source-serif/tree/80d3f8894c09c937bebfa9011247d2e1c79fd6f4), pinned to commit `80d3f8894c09c937bebfa9011247d2e1c79fd6f4`.
- Upstream file: `WOFF2/VAR/SourceSerif4Variable-Roman.ttf.woff2`, copied without modification or subsetting.
- Variable axes: weight 200-900 and optical size 8-60; browser optical sizing remains automatic.
- Coverage includes Vietnamese precomposed letters and combining marks.
- License: SIL Open Font License 1.1; the complete upstream copyright and license text is in `SourceSerif4-OFL.txt`.

The font and its license are precached for offline use. The normal face is shipped; italic text uses browser synthesis.
